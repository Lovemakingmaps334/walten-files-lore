# The Walten Files Lore Archive

This repository contains a simple static GitHub Pages site for a fan-made lore guide about The Walten Files.

## Publish on GitHub Pages

1. Open your repository on GitHub.
2. Go to **Settings**.
3. Select **Pages**.
4. Set the source to **Deploy from a branch**.
5. Choose **main** and the root folder (`/`).
6. Save.

Your site will then be published at:

`https://<your-username>.github.io/walten-files-lore/`

## Files included

- `index.html` — the homepage and lore structure
- `style.css` — page styling and layout
- This README — project notes

## Notes

This project is a fan archive created for storytelling and lore exploration. It is designed to be easy to customize, expand, and host for free on GitHub Pages.
